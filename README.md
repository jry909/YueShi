# YueShi Demo

新成员请先阅读 [新成员使用说明书](新成员使用说明书.md)。它包含从空白环境安装、示例与真实评估、密钥配置、完整操作流程和常见故障。

Windows 首次运行：安装 Node.js 24 LTS，在本文件所在目录打开终端，执行 `npm.cmd ci`，然后执行 `npm.cmd start`，访问 http://localhost:3210。
macOS / Linux 使用 `npm ci` 和 `npm start`。

本分享包不包含依赖目录或任何个人密钥。示例回放不需要密钥；本地真实评分需要自行配置 `.env`。团队统一网页可以让成员免安装、免个人密钥，但当前尚未部署，详见说明书第 9 节。

技术细节见 [技术说明](技术说明.md)。
